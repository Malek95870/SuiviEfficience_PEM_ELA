Comment ça marche
Chaque technicien pousse ses données vers un « bin » partagé sur jsonbin.io à chaque sauvegarde de journée. Le superviseur récupère toutes les données depuis ce bin en un clic.

Mise en place (à faire une seule fois) :
1. Créez un compte gratuit sur jsonbin.io
2. Créez un nouveau bin (contenu initial : {})
3. Copiez votre X-Master-Key et l'ID du bin
4. Distribuez ces deux infos à tous les techniciens (à coller ci-dessous)
5. Cochez « Activer » sur chaque poste → tout est automatique
★
💡 Alternative fiable recommandée : npoint.io
Pourquoi changer ? JSONBin limite la version gratuite à 10 000 requêtes/mois et exige une clé maître. npoint.io est gratuit, illimité, sans inscription, et 100 % compatible avec le format JSON utilisé par cette app.

Mise en place de npoint.io (5 minutes, sans compte) :
  1. Allez sur npoint.io dans votre navigateur
  2. Saisissez {} dans la zone de texte centrale, puis cliquez sur « Save »
  3. L'URL devient https://api.npoint.io/xxxxxxxxxx — notez le code xxxxxxxxxx (10 caractères)
  4. Pour autoriser l'écriture publique, cliquez sur 🔒 « Schema » en haut puis désactivez « Read-only ». Conservez ce code privé.
  5. Collez ce code à la place de l'ID du bin ci-dessous, et cochez la case « Utiliser npoint.io » à la place de JSONBin
  6. Aucune clé n'est nécessaire — laissez le champ Clé maître vide
Bonus : npoint.io fonctionne aussi très bien comme miroir de secours en cas d'indisponibilité de JSONBin.
Autres alternatives gratuites : JSON Silo, JSONStorage.net, ou (pour un usage entreprise) un GitHub Gist privé avec un Personal Access Token.

Information sur le traitement des données

Outil interne d'essai — Atelier PEM Bezons

Cette application enregistre votre activité professionnelle quotidienne (heures travaillées, appareils traités, efficience calculée). Les données traitées sont les suivantes :

  • Identifiant et nom du technicien
  • Date et heure des interventions
  • Type d'intervention (TAR, TAN, ETC)
  • Famille d'appareils et numéros de dossier
  • Indicateurs d'efficience individuels

Lieu de stockage : les données sont stockées localement sur votre navigateur (localStorage). Si le partage cloud est activé, elles sont également transmises au service configuré par votre encadrement.

Finalité : suivi d'activité atelier et accompagnement des techniciens dans l'atteinte des objectifs d'efficience.

Vos droits : conformément au RGPD, vous disposez d'un droit d'accès, de rectification, d'opposition et d'effacement. Pour exercer ces droits, contactez votre responsable hiérarchique ou le DPO de l'entreprise.

Cet outil est actuellement en phase de test interne et n'a pas encore été officiellement validé par l'entreprise. Aucune décision RH ne doit être prise sur la base des seules données qu'il produit.
